Clustering tools is inserted within the viewer 
as viewer.clusterTool object


ClusterTool create PointCluster objects and 
are stored withing the scene as
viewer.scene.pointCLusters=[]



ClusterTool methods

activate()
deactivate()


PointCluster:

segments=[{pointcloudid:xxx,  segmentid:yyy}]
classification
active: To indicate segments being added/ existing
selected:  true/false, to highlight the whole cluster

 methods:
 - activate()
 - deactivate()


PointClusters contain a segment List


PointClusters are just information to be rendered within the vertex shader and color based on a classification value given a pointcloud attribute, which is a segment_id.

Rendered information are all the clusteredSegments and from all PointClusters,,, segments and tempSegments

Currently , they are being colored into the getClassification() method and getClip() in the vertex shader pointcloud.vs

Shader only deals with segment_id attributte, clusteredSegments (list of all semgents), segmentClassification array and others: 

clusteredSegments[segment a, segment b, ...]    segmentClassification[ class_segment_a, class_segment_b], so they share the same size

colors are assigned based on a LookupTable array mapping segmentClassification -> lookupTable using a 255 array

getClassification() deals with the main classification color

getClip() deals with clip, highlight and active colors on basis of current classification color




Attributes, uniforms and  defines are set/commited  commited  into Renderer.renderOctree for every frame.
